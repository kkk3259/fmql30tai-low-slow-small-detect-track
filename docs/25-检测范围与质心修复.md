# 25 · 检测范围与质心溢出修复（2026-10-29 夜）

## 一、发现并修复的真 bug：质心坐标 16 位溢出

### 现象
板上把同一个目标放到画面不同位置，PL 报回的坐标会"跑到左上角"：

| 目标位置 | 边长 | 修复前 PL 报回 |
|---|---|---|
| (320,180) | 8 px | (321,180) area=56 ✓ |
| (320,180) | **16 px** | **(48,180)** area=240 ✗ |
| (320,300) | 16 px | **(48,26)** ✗ |
| (320,340) | 16 px | **(48,66)** ✗ |

用户观察到的"目标一直在顶部、调画面也不动"就是它。

### 根因
`candidate_extract_stream.v` 里质心累加器 `csumx/csumy` 只有 16 位：

```
面积 × 坐标 = 240 × 320 = 76,800 > 65,535  →  溢出回卷
(76800 − 65536 + 120) / 240 = 47.4 → 48     （与实测 48 完全吻合）
```

同时除数只取了面积的 **低 8 位**（`carea[7:0]`），面积 > 255 时除法也错（`MAX_AREA` 提到 2047 后必然踩中）。

### 修复
| 项 | 原 | 新 |
|---|---|---|
| `csumx/csumy` | 16 位 | **24 位**（2047×639 = 1.31 M < 2²¹） |
| 除法除数 | 8 位（截断） | **16 位** |
| 串行除法迭代 | 17 次 | 24 次（每标签 +14 拍，64 标签仍在 10.4 ms 预算内） |

仿真：`tb_ccl_centroid.v`（640×360，16×16 亮块 @ 320,180）→ x=327 y=188 area=256 peak=240 ✓
真机：新位流（2026-10-29 22:46:53，WNS +1.746 ns）实测 8 px / 16 px × 四个角与中心，**全部命中**：

```
     8 (320,180) | (321,180,a=  56,p=200)  OK
     8 (560,320) | (561,320,a=  56,p=200)  OK
    16 ( 80,320) | ( 81,320,a= 240,p=200)  OK
    16 (560,180) | (561,180,a= 240,p=200)  OK
```

## 三、时域差分（帧差法）落地

`ps/cam_pipe.py` 新增 `--motion-frac` / `--motion-thr`：候选周围 13×13 区域内"相对上一帧变化超过 8 灰度"的像素占比低于门限则丢弃。

板上实测 `--motion-frac 0.12`：原生候选 8 个 → **1~4 个**，帧率 29.1 fps、PL 11.1 ms（几乎无额外开销）。
