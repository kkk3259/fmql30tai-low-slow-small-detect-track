# 寄存器映射与候选表窗口（踩坑记录）

> 2026-10-29 补。起因：PS 侧脚本一度全用 `0x40/0x44` 读候选表窗口，而 RTL 里窗口其实在 `0x10`，
> 导致“读回来的候选表是垃圾 / 只有 5 个候选”的误判。这份文档是**唯一权威**，RTL 改动时同步更新。

## 1. 权威寄存器表（`repo/pl/rtl/ip2_axi_top.v`，6 位 s_axi 地址）

| 偏移 | 写 | 读 |
|---|---|---|
| `0x00` | `start`（bit0，自清零） | `{31'd0, start_r}` |
| `0x04` | `frame_addr` | `frame_addr` |
| `0x08` | `result_addr` | `result_addr` |
| `0x0C` | — | `STATUS`（见下） |
| `0x10` | **候选表窗口字索引**（0~112） | **该字的 32 位数据** |
| `0x14` | — | `VERSION` = `0x00010000` |
| `0x18`~`0x38` | — | `legacy_ram[0..8]` = **36 字节兼容视图** |
| `0x3C` | — | `st_mirror` = `{done, err, 14'd0, frame_id}` |

`STATUS`（`0x0C`）位域：`{8'h00, frm_cnt, n_cand_r, 5'd0, done, err, busy}`
- bit0 `busy`、bit1 `done`、bit2 `err`、bit9:3 附近起是 `n_cand`（当前帧候选数，左裁剪到 0~127）、高 8 位是帧计数。

## 2. 两个必须记住的坑

### 坑 1：`0x40` 会绕回 `0x00`
总线是 **6 位**（`s_axi_awaddr[5:0]`），所以：
- 写 `0x40` → 实际写 `0x00` = **误触发一帧**（`start`）；
- 读 `0x44` → 实际读 `0x04` = 读回 `frame_addr`。
→ 早期“窗口在 0x40/0x44”的写法来自一版 8 位地址的实验分支，该分支已回退。现在一律用 `0x10`。

### 坑 2：窗口读的是“索引寄存器选中的字”，同址读写
`0x10` 写 = 设索引，`0x10` 读 = 取该字。所以脚本里必须严格“写索引 → 读数据”配对，
中间不能插别的寄存器写（会改索引）。

### 视图怎么自动判定（`ps/cand_read.py --view auto`）
```
索引默认 0（复位值），因此：
  rd(0x10) == rd(0x18)  →  有窗口（新构建），可用 113 字 / 64 候选
  否则                   →  老构建（如 A 的合并位流），退化为 0x18 起 36 字节视图
```
判定过程不写任何寄存器，避免把老构建里 `0x10`（可能是 `FRAME_ID`）写坏。

## 3. 已统一修改的脚本（`ps/fix_win.py`）

`cam_pipe.py`、`cand_read.py`、`probe64.py`、`probe64b.py`、`probe_one.py`、`probe_sizes.py`、`size_sweep.py`
全部把 `R_CIDX/R_CDAT` 从 `0x40/0x44` 改回 `0x10`，并把注释里的错误地址说明一并纠正。

> 教训：地址常量只能有一个来源。后续任何寄存器改动，先改这份文档，再改 `cand_read.py`，
> 其它脚本一律复用它（不要再各写一份常量）。

## 4. 附：Top-Hat 的两种模式（2026-10-29 新增 `MODE` 参数）

`repo/pl/rtl/tophat_5x5_stream.v` 增加 `parameter MODE = 0`：

| MODE | 语义 | 适用 |
|---|---|---|
| `0` | **Top-Hat** = 原图 − 开运算（亮背景上的暗目标会被抹掉） | 亮背景、暗目标场景（原设计） |
| `1` | **Black-Hat** = 闭运算 − 原图（暗背景上的亮小目标） | 我们实测的靶图/夜间场景 |

S 的 Pd-Fa 权衡表（`tools/bench_cfar_tradeoff.py`，`report` 第 16 节）给出的结论：
Top-Hat `k=4` → 召回 55% / 34.7 候选；Top-Hat `k=3` → 75% / 99.4；Black-Hat `k=3` → 86% / 47.5（推荐）；Black-Hat `k=2, win=51` → 94% / 183。
→ 我们下一步就是 Black-Hat + CFAR K=3，与他的表对齐后再上板复测尺寸矩阵。
