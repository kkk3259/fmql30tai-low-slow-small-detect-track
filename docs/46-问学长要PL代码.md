# 46 问学长：有没有 PL 端这几段代码

学长好，我们的三域工程（官方 fpai_demo + 自己的 PL 检测核）位流能跑，但检测结果不稳。
想问问你那边有没有 **PL 端** 这几段的现成代码能参考：

**1. 行流读帧适配层**
就是平台 512 位 `M_AXI_HP` 口 → 自己检测核的那一层。
我们这层现在**每帧起始对齐不定**：同一张图，检测出来的 x 坐标有时偏 62~64 像素，
有时不偏，换个进程跑又是另一个值（64 字节刚好是 1 个 AXI beat，怀疑 FIFO 里有上一帧残留）。
想看你当年是**怎么保证每帧从第 0 行第 0 列开始**的，有没有 `frame_start` 之类去复位指针。

**2. 候选表输出 + 边界处理**
我们的候选表只有 8 个槽位，结果经常**被画面边缘的伪目标占满**：
真目标 peak 只有 60~70，而画面补的 pad 边沿 peak 有 200+，8 条全被它吃掉。
想看你那边候选表是怎么排的（按 peak 还是按扫描顺序），以及**画面边界是怎么排除**的
（RTL 里排还是 PS 侧过滤）。

如果这两段有代码，**整段发过来也可以**（或者告诉我仓库里哪个文件，我自己拉），
有完整工程更好，谢谢学长！
