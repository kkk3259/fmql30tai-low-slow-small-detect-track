## 一、检测器准确率：首次拿到带真值的数据

### 1.1 测试集

问题：之前只有"人眼看着还行"这种主观判断，没有数字。

做法：写 `repo/tools/gen_testset2.py` 生成 12 段 × 120 帧 640×360 视频，每帧带真值 JSON。

**目标不再是方块**，而是按真实形态做的剪影（8 倍超采样后缩回，带抗锯齿）：

| 目标 | 画法 |
|---|---|
| 鸟 | 展翅多边形，可旋转 |
| 四旋翼 | 机身 + 4 个旋翼弧 |
| 飞机 | 十字（机身 + 机翼） |
| 车 | 矩形 + 深色车窗 |

**摄影级退化**（让目标和真拍的一样"糊"）：

- 距离模糊：高斯 PSF，`σ = 0.35 + 0.02 × 边长`
- 运动模糊：沿速度方向线性卷积
- 传感器噪声：泊松 + 高斯（夜间 8σ）
- 暗角 25%、JPEG q88

背景四类：天空（漂移云）、草地（竖向草叶高频）、海面（横向波纹）、夜间（强噪点）。

产物：`D:\firstharness\dl\testset2\`（12 段，19.1 MB）+ `testset2_sheet.jpg`（拼图）

### 1.2 评估方法

`repo/ps/eval_testset2.py`：真值标注框与候选框做一对一贪心匹配（中心距 ≤ 目标半边长 + 3 px），算召回/精确/定位误差；支持 `--inv both`（正、反两种极性各跑一遍取并集）、`--border`（屏蔽边框伪影）、`--pre`（PS 侧预处理）。

## 二、两条"想提升灵敏度"的路，走不通的已证伪

### 2.1 PS 侧局部均值高通（❌ 反而更差）

思路：先在 PS 里做 `img - blur31(img)`，把云的慢变纹理拉平，小目标就好检。

实测（`--pre hp`，同上 8 段）：

```
平均召回 2.3%   平均精确 1.3%   候选 5.2/帧
```
比不处理（13.5%）**更差**。

原因：31×31 均值窗里也包含目标自身的能量，减掉后目标反差被削弱；而 Top-Hat 之后本来就没剩多少。

### 2.2 裸 Vivado 流程重编 K=0/FLOOR=2（❌ 出不了可用位流）

写了 `synth/vivado/rebuild_fast.tcl`（read_verilog + synth_design + place + route，无工程）。

两次失败：

```
ERROR: [Place 30-99] Placer failed with error: 'IO Clock Placer failed'
ERROR: [Common 17-69] Command failed: Placer could not place all instances
```

补了最小 XDC（`create_clock -period 20 [get_ports clk]` + 降级 NSTD-1/UCIO-1）仍然报同一个错。

**根因**：裸流程没有板级引脚约束，时钟端口没有落到 clock-capable pin；更根本的是——**裸 AXI 端口的位流本来就没法和 PS 对接**，我们真正能用的位流必须来自带 PS7 的 BD 工程（`ip2_ps4`）。

⇒ K/FLOOR 的敏感度实验，只能走"工程流 + 重打包 IP"，那是 25~40 分钟一轮，本轮时间不够。

## 三、三域合并：位流在布线

- 顶层 `work/ours3d/ai7030_ours_top.v`：`ps_ai_wrap_demo`（EDIF：PS7 + AI_Mate + MIG + HDMI）+ `ip2_user_op #(.SE(5), .MAX_CAND(16))`
- 流程：`READ_OK → SYNTH_OK → OPT_OK → PLACE_OK`，资源 LUT 71,430（90.88%）
- 布线：`Phase 4.2 → Phase 4.3 Global Iteration 2`，overlaps 从 99,858 降到 **1,777**，CPU 已 126 分钟
- 判断：能收敛，但 90.9% 占用下布线很慢（不是卡死）

已加入的调试设施（一次加满，不再逐轮加）：

| 设施 | 地址/方式 | 用途 |
|---|---|---|
| 调试计数器 | `0x90` AR 握手 / `0x94` R 返回 / `0x98` 看门狗 / `0x9C` 状态快照 | 判断跨时钟域卡在哪一步 |
| 片上 LA | `0xA0` 索引 / `0xA8` 状态 / `0xAC` 清空，256 条 × 32 位 | 事后回放事件序列（5 = 看门狗超时触发冻结） |
| 读超时保护 | `rd_tmo` 到 4095 拍强制返回 `0xDEADBEEF` | 核死掉也不拖死 PS |
