# 指标台账（所有引用数字的出处登记）

> **用途**：报告、答辩、PPT 里出现的每一个数字，都在这里登记测试条件。
> **为什么需要**：同一个指标（如"PL 检测单帧"）在不同配置下是不同值（4.19 / 10.6 / 13.8 ms），
> 混用会造成"同一件事三个数"的误会。本次编写过程中出现过三次这类问题，故建此台账。
> **规则**：任何数字在别处引用时，必须连配置一起写，例如「13.8 ms（四尺度合并）」而不是只写「13.8 ms」。

## 六、常见误用（编写过程中真实发生过的）

| 误用 | 正确写法 | 发生次数 |
|---|---|---|
| 「高斯使检出率 95%→81%」 | **93.6% → 47.9%** | 1 次 |
| 「端到端 148.83 → 60.60 ms」 | **148.83 → 41.00 ms**（60.60 是各环节相加，非实测）| 1 次 |
| 「独立位流 13.50 ms / 28.9 fps」 | **13.8 ms / 24.3 fps**（13.5/28.9 是单遍配置，报告正文未采用）| 1 次 |
| 「较独立位流快 3.2 倍」 | **3.3 倍**（13.8 / 4.19 = 3.29）| 1 次 |

**⇒ 三条教训**：
1. 不自己相加/推算，**用实测值**
2. 引用别的配置的数字前，**先确认报告正文用的是哪一套**
3. 同一指标有多个值时，**必须带配置**
