| 元素 | 状态 |

## 2. 页面靠哪些字段工作（`/info` 契约）

页面直接复用独立版模板，所以 `/info` 必须提供这些键 —— **已经全部补齐并每帧更新**：

```
fps, PL_ms, lat_ms, cap_ms, enc_ms     ← 指标卡 + 曲线
raw, stable, n, cands[]                 ← 候选数 / 稳定数 / 目标列表
gamma, msk, stretch, invert             ← 滑条位置
（三域额外）pl_ms, npu_ms, frames, ncand, ntrk, err
```

`cands[]` 每项：`id / x / y / area / peak / spd / p`（`p` = NPU 概率，null 表示没跑）。

## 3. 三个滑条（语义与独立版一致）

| 滑条 | 位置 → 实际值 | 作用 |
|---|---|---|
| **灵敏度** | 保守 `gamma 0.12` / 中 `0.08` / 激进 `0.05` | gamma 只改“送进 PL 的那份灰度”，压缩动态范围让弱目标更容易过 CFAR 门限；**画面亮暗不变** |
| **目标大小** | 小 / 自动 / 大 | 三域位流没有双尺度，这个滑条只记录、不改变行为（保持界面一致） |
| **场景** | 室内（不取反）/ 逆光（**取反**）/ 混合（取反） | 取反 = 把 `255−gray` 送 PL，等价 Black-Hat，用于逆光天空里的鸟/无人机 |

网页上拖滑条实时生效（走 `/set`，不用重启进程）：
`/set?sens=1&size=1&scene=1`、`/set?gamma=0.08`、`/set?invert=1`、`/set?npu=0`、`/set?quality=80`

## 4. 部署与启动

```bash
cd /root
git clone https://gitee.com/kkk3259/fmql30tai-low-slow-small-detect-track.git ip2repo 2>/dev/null \
  || (cd ip2repo && git pull)
cp ip2repo/ps/cam3d_pipe.py /root/ip2/cam3d_pipe.py

# 停旧服务
/etc/init.d/ip2d3 stop 2>/dev/null; pkill -9 -f 'cam3d_pipe[.]py'; sleep 2

# 启动（彩色画面 + gamma 0.08）
cd /root/ip2
python3 cam3d_pipe.py --port 8080 --gamma 0.08 --color 1
```

浏览器：`http://<板子IP>:8080/`

三种常用组合：

```bash
python3 cam3d_pipe.py --port 8080 --gamma 0.08 --color 1              # 室内 / 靶图
python3 cam3d_pipe.py --port 8080 --gamma 0.08 --invert 1 --color 1   # 逆光 / 找暗目标
python3 cam3d_pipe.py --port 8080 --npu 0 --gamma 1.0 --color 1       # 只看检测、不跑 NPU
```

## 6. 已知差异（不是 bug）

| 项 | 三域版 | 独立版 |
|---|---|---|
| SE（结构元） | 5 → 只认 **2~4 px** | 31 → 认 **6~28 px** |
| PL 单帧 | **4.2 ms** | 14~15 ms |
| NPU | 有（1.6 ms/候选） | 无 |
| 双尺度降采样 | 无 | 有 |

同一个场景，三域版框会比独立版少，**是位流里 SE 不同造成的**，不是界面或 PS 逻辑问题。
