# PLC 检测链路改动台账（2026-11-02）

> 目的：把每一处"提升检出率但会掉帧率"的改动单独记下来，方便后面按帧率指标做取舍。
> 当前目标：**帧率 ≥ 20 fps**（相机上限 30）。

## 一、板级实测耗时（`ps/bench_nocam.py`，视频喂帧，60 帧平均）

| 阶段 | 每帧耗时 | 占比 | 说明 |
|---|---|---|---|
| 读帧（文件） | 10.1 ms | 13% | 真实相机换成 `cap.read()` 阻塞 ~33 ms |
| **灰度+缩放** | **8.4 ms** | **11%** | `INTER_AREA`，可降到 3.8 ms |
| **PL 检测** | **23.1 ms** | **30%** | 触发+等待+读表 |
| 裁剪拼图 | 0.9 ms | 1% | |
| **NPU mosaic** | **32.5 ms** | **42%** | 每帧跑；隔帧摊薄到 16.4 |
| **合计** | **77.7 ms** | | **12.9 fps** |

## 二、改动台账（按"提升检出 / 掉帧率"分类）

### A. 提升检出率、代价小或为零

| # | 改动 | 效果 | 帧率代价 |
|---|---|---|---|
| A1 | **中心距聚类** `r=clamp(2.5√area,14,40)` | 一个目标碎片合成一个，t3 格子里候选从 49→有效 | 0（纯 CPU，<1 ms） |
| A2 | **裁剪窗按面积放大** `clamp(3√area,96,128)` | NPU 看到完整目标，f130 从 4 错位框→1 准框 | 0 |
| A3 | **50% 包含度合并** | 同一目标多框合一 | 0 |
| A4 | **EMA 平滑 + 航迹保持** `A=0.35, R=46, MISS=4` | 框不再闪、丢帧不消失 | 0 |
| A5 | **保护区重检** `CONF 0.45→0.20, HITS≥6` | 目标突然丢失时低阈值救回，hit/f 1.20→1.57 | 仅在"丢失帧"触发，约 +4 ms/次 |
| A6 | **只画确认框 / PL 框改淡** | 画面干净、不误导 | 0 |
| A7 | **`MAX_CAND` 16→32**（RTL） | 候选表不再被边界占满 | 0（硬件并行） |
| A8 | **`BORDER=24`**（RTL） | 边界伪目标清零 | 0 |
| A9 | **`frame_kick`**（RTL） | 相位漂移从随机变恒定 +63 | 0 |

### B. 提升检出率、明确掉帧率

| # | 改动 | 效果 | 帧率代价 |
|---|---|---|---|
| B1 | **双极性（同一检测器跑两遍）** | 暗目标/逆光场景召回明显提升 | **PL 翻倍：15.6→31 ms** |
| B2 | **真隔帧双极性**（每 2 帧跑一次取反） | 保留一半收益 | **+8 ms（摊薄）** |
| B3 | **彩色显示** | 观感 | **JPEG 编码 15.8→29.4 ms（+13.6）** |
| B4 | **NPU 每帧跑** | 框更新率 30 Hz | 32.5 ms；隔帧后 16.4 ms |

## 三、提速项（不改检出逻辑）

| # | 改动 | 省时 | 风险 |
|---|---|---|---|
| C1 | `INTER_AREA` → `INTER_LINEAR` | **−4.5 ms** | 略失锐度，可接受 |
| C2 | NPU 隔帧（`YOLO_EVERY=2`） | **−16 ms** | 框更新率降到 15 Hz |
| C3 | 彩色 → 灰度推流 | **−13.6 ms** | 画面变灰 |
| C4 | `INTER_NEAREST` | −7.3 ms | 会漏小目标，不用 |

## 四、算得出来的组合

| 组合 | 每帧 | 帧率 |
|---|---|---|
| 全开（当前） | 77.7 ms | **12.9** |
| C1 + C2 | ~54 ms | **18.5** |
| C1 + C2 + C3 | ~40 ms | **25** |
| 全开但 NPU 隔帧 | 59.1 ms | 16.9 |

**结论：要稳定 20+，至少要做 C1+C2；如果还不够，C3（灰度推流）是最大的一块。**

## 五、取舍建议（按性价比排序）

1. **先做 C1 + C2**（不改画面观感，白赚 20 ms）
2. 若还不够 → **C3 灰度推流**（掉观感，但省 13.6 ms）
3. **B1 双极性**是检出率提升最大的，但代价 15 ms —— 建议**只在暗场景/逆光时打开**，白天不用
4. B4 NPU 每帧保留（框更新流畅），不要为帧率回到逐帧跑
