## 1. 帧率优化：23.7 → 27.6 fps

分段计时（`cam_pipe.py` 内置 `trk_ms`/`PL_ms`/`enc_ms`，`/info` 可读）：

| 阶段 | 优化前 | 优化后 | 说明 |
|---|---|---|---|
| 采集 `cap` | 31.7 ms | 32.2 ms | 相机 30 fps 上限，无法再降 |
| PL（多尺度两遍） | 16~17 ms | 13.8 ms | 第二遍改每 3 帧一次（`--ms-every 3`） |
| 跟踪 `trk` | 5.8~6.8 ms | 2.7~2.8 ms | 候选预剪 `MAX_IN` 24→12 |
| 编码 `enc` | 12.3~13.3 ms | 12.9~13.4 ms | 灰度流（imencode GRAY 比 BGR 快一倍） |
| 端到端 `lat` | 44 ms | 41 ms | 采集完成 → 画完框 |
| **帧率** | **23.7 fps** | **27.6 fps** | `/info` 三次采样 27.3 / 27.6 / 27.8 |

## 3. 检出尺寸矩阵（真机，`ps/size_sweep_ms.py`）

三通道分别触发：A 全分辨率、B 2× 降采样、C 3× 降采样；括号为 PL 回报的 `(x,y,area)`，OK = 坐标在 (320,180) ±3 且面积合理。

| 目标边长 | A 全分辨率 | B 2×→映回 | C 3×→映回 | 合并结论 |
|---|---|---|---|---|
| 2 px | (321,180,a=2) OK | OK | 乱 | ✓ |
| 4 px | (321,180,a=12) OK | 乱 | (325,181,a=36) OK | ✓ |
| 6 px | (321,180,a=30) OK | (323,181) OK | (325,181) OK | ✓ |
| 8 px | (321,180,a=56) OK | 乱 | (325,181) OK | ✓ |
| 12 px | 乱 | (323,181,a=120) OK | (325,181) OK | ✓ |
| 15 px | (322,180,a=210) OK | OK | 乱 | ✓ |
| 20 px | (321,180,a=380) OK | OK | 乱 | ✓ |
| 24 px | 未检出（SE=21 上限） | (323,181,a=528) OK | 乱 | ✓ |
| 30 px | 未检出 | 乱 | (325,181,a=900) OK | ✓ |
| 40 px | 未检出 | (323,181,a=1520) OK | OK | ✓ |
| 50 px | 未检出 | 未检出 | 乱 | ✗ |
| 60 px | 未检出 | 未检出 | (325,181,a=3240) OK | ✓ |
| 70 px | 未检出 | 乱 | 未检出 | ✗ |

**结论**：合并后**稳定覆盖 2~40 px**，60 px 也能命中；**50 px、70 px 仍是缺口**。
50 px 缺口原因：3× 降采样后是 16.7 px，落在 SE=21 的检出上边界附近，再加上面积筛选边界被切。
70 px 缺口原因：3× 后 23 px 已超出 SE=21 上限。

**下一步（若要补 50/70）**：再加一遍 4× 降采样（70 px→17.5 px 落进窗口）；代价是每 3 帧多一次 PL（约 +4 ms）。
