# 29 - 三域联合（IP2 + AI_Mate NPU）阻塞点实测结论

时间：2026-10-30 21:10 前后
结论一句话：**本机两条工具链都缺“AI 引脚”这一环的关键素材**，三域联合今晚无法闭合。以下全部是本机实测证据，不是推测。

## 1. Vivado 2018.3：器件库里没有 AI 引脚
- 官方三域工程（`official\fpai_demo_fpga\fpai_demo_fpga\fpai_demo_vivado.xpr`）综合必报
  `ERROR: [Synth 8-448] named port connection 'AI_IN1549' does not exist for instance 'PS7_inst' of module 'PS7'`
  位置：`...\ipshared\8fd3\hdl\verilog\processing_system7_v5_5_atc.v:6133`。
- 查 `D:\Xilinx\Vivado\2018.3\data\verilog\src\unisims\PS7.v`（848 KB）：`AI_IN1549` 命中 **0 次**，文件未改动。
- 装了 S 给的 `ip_patch_5.3.2.1_030ai_vivado2018.zip` 后，`database_check.log` 只有 `#IP Patch version in project root directory:5.3.1.8`，**没有任何器件库替换记录**；补丁包内唯一带 AI 信息的是 `030ai\zynq.lib`（Synopsys 库，不是 RTL）。
- 人为删 AI 引脚不可行：删 `AI_IN*` 3686 行 → 冒出 `AI_CLK*` 182 行 → 再删 → 冒出 `DEBUGDATA*`，砍不完。

## 2. Procise：AI 引脚在 `PCPU7_PLUS` 原语里，但引脚数对不上
- Procise 器件库 `D:\FudanMicro\Procise\db\fmz7\fpga.lib` 里有 **两个** PS 原语：
  - `cell(PCPU7)`：620 根引脚，**无 AI 引脚**，命名 `DDRA/DDRDQ/GP0*`
  - `cell(PCPU7_PLUS)`：**5119 根引脚，含 `AI_IN*` 680 根 + `AI_OUT*` 606 根 = 1286 根**
- 而官方三域工程的 `PS7`（Vivado 侧）需要 **3686 根 AI 引脚**（A 统计 3907 根含 DEBUGDATA）。
- ⇒ **1286 ≠ 3686**，这不是命名翻译能解决的，是两代 AI 接口的差异。

## 3. Procise 吃不下 Vivado BD 网表（另一条路也堵）
- 直接把 BD 产物（`bd/ps_ai/synth/ps_ai.v` + `ipshared/*/hdl/*.v`）喂给 Procise：
  - 若加 `ipshared` 里 Xilinx IP 实现文件 → `ELAB_FAIL`（Procise 解析不了 `axi_register_slice_v2_1_vl_rfs.v` 这类 Vivado 专有实现）
  - 若不加 → `axi_register_slice_v2_1_18_axi_register_slice unknown` 引发多米诺，六条错其实是同一个缺失模块
- 直接例化 PS7 包装（`processing_system7_v5_5_processing_system7.v` + 6 个 atc 文件）：
  `ERROR(ELAB-E-6): processing_system7_v5_5_atc.v(5420), Module call "PS7_inst" has more terminals than its module declaration "PCPU7"`
  ⇒ Procise 把 `PS7` 解析成了自己的 `PCPU7`（620 引脚），而例化传了 3686 根 AI 引脚。

## 6. 补充（21:20）：AI_Mate 为什么离不开 AI 总线 —— 端口实证
解析 `AI_Mate.edif` 顶层（135 个端口）后得到决定性证据：

- `M_AXI_GP0_*` / `M_AXI_GP1_*`（24 根）**只有握手信号**：ARREADY/ARVALID/AWREADY/AWVALID/BREADY/BVALID/RLAST/RREADY/RVALID/WLAST/WREADY/WVALID。
  **没有 ARADDR / AWADDR / WDATA / RDATA / BRESP / RRESP**。
- `S0~S3_AXI_HP_*`（48 根）同样只有握手类信号，没有地址数据。
- `pl_*`（40 根）也是握手/时钟/扫描/自检：`pl_arvalid/arready/awvalid/awready/bvalid/bready/rlast/rready/rvalid/rst_n/itf_clk/scan_*/bist_*`。

⇒ **AI_Mate 的 AXI 地址与数据全部经由 FMSH 私有 AI 总线（AI_GP/AI_HP）传输**，`M_AXI_GP`/`S_AXI_HP` 上只留了跨时钟域的握手。
因此 AI_Mate **无法用标准 AXI 直连**；标准 PS7（无 AI 引脚）接不上它。

- 另外它还需要：`ddr3_init_done`（输入，需外部 DDR3 控制器）、`app_*` 7 根（MIG app 口控制子集）、`hp_clk`。

⇒ 结论：**30T 上要用 NPU，必须拿到按 30T AI 总线（1286 根）编译的 AI_Mate 网表**。
