# 47 验证规范（团队约定，2026-11-02）

## 铁律

1. **所有检测效果验证一律用视频**，不用单张图片。
   - 单图只能说明"这一帧能不能出框"，不能说明稳定性。
   - 视频能同时暴露：框抖动、丢帧、相位漂移、误报率。
2. **验证结果必须给出视频文件 + 抽帧拼接图**，不能只报数字。
3. 分析画面统一走 **PL 粗筛 → 裁 ROI → 放大 → yolo 判**，不走整帧 yolo。
4. 列相位必须**进程内自校准**（phase_cal3.estimate），禁止硬编码 62/64/160。
