### 5.3 参数扫描数据（Pd–Fa 权衡，可作报告表格）

| 配置 | 检出率 Pd | 虚警(次/分钟) | 单帧耗时 |
|---|---|---|---|
| 阈值过松（floor=1，面积≥1） | 100 % | 12600 | 5.69 ms |
| floor=3，面积≥2 | 44.7 % | 0 | 4.35 ms |
| floor=4，面积≥3 | 0.7 % | 0 | 4.05 ms |
| **关高斯 + 降采样2× + floor=3 + 面积≥2（采用）** | **94.7 %** | 384 | **4.19 ms** |
| 关高斯 + 不降采样 | 90.7 % | 2172 | 20.10 ms |
| 开 3×3 高斯 + 不降采样 | 81.3 % | 0 | 18.45 ms |

**三条结论**：① 3×3 高斯会把小目标削掉（Pd 94.7%→81.3%）；② 降采样 2× 反而更快更好（耗时降 5 倍）；③ 虚警与检出是跷跷板（后续用航迹确认压制虚警）。
