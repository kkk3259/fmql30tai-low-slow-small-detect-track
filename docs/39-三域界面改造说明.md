# 三域网页界面改成独立版样式 —— 给 S 的说明

> 2026-11-01 17:10。变更涉及 `ps/cam3d_pipe.py`（三域实时链路），不涉及位流，**不需要重编 FPGA**。

---

## 1. 改了什么

之前三域页面的界面是我临时写的极简版（一行文字 + 一张图），你看不到参数、曲线、目标列表。现在**直接复用独立版 `cam_pipe` 的整套界面模板**：

| 界面元素 | 说明 |
|---|---|
| 顶部标题栏 | 状态灯 + `pl · 0x400C0000` |
| 实时指标卡 | 帧率 / PL 单帧 / 采集 / 编码 / 候选·稳定 / 端到端时延 |
| 三条滑条 | **灵敏度**（gamma 0.12/0.08/0.05）、**目标大小**、**场景**（室内亮目标 / 逆光 / 混合） |
| 耗时曲线 | 近 60 帧 PL 耗时折线 |
| 目标列表 | ID / X / Y / 面积 / 峰值 / 速度 |
| 视频区 | 彩色画面 + canvas 叠框（绿=确认、红/橙=疑似或 NPU 判非目标） |
| 截图保存按钮 | 存 PNG |

### 三域特有的一列

框上的标签在独立版 `#id 12px pk108` 之后**多了 NPU 概率**：`d0.87` 表示 NPU 判为“是目标”的概率 0.87；`d0.00` 表示判为非目标；没跑 NPU 时不显示。

### 参数语义（跟独立版一致，已实测映射）

| 滑条 | 位置 → 实际值 | 作用 |
|---|---|---|
| 灵敏度 | 保守 → `gamma 0.12`<br>中 → `gamma 0.08`<br>激进 → `gamma 0.05` | gamma 只改“送进 PL 的那份灰度”，压缩动态范围，让弱目标更容易过 CFAR 门限；**画面亮暗不变** |
| 目标大小 | 小 / 自动 / 大 | 三域位流**没有双尺度**，这个滑条目前只记录、不改变行为（保持界面一致） |
| 场景 | 室内 → 不取反<br>逆光 → **取反** + 找暗目标<br>混合 → 取反 | 勾上取反 = 把 255−gray 送 PL，等价 Black-Hat，用于逆光天空里的鸟/无人机 |

> 提醒：三域位流的检测器是 `SE=5`，只能看 **2~4 px** 的目标；独立版是 `SE=31`，能看 **6~28 px**。
> 所以**同一个场景，独立版框会比三域版多**，这是位流差异，不是界面问题。

## 3. 怎么跑

```bash
# 1) 先停掉正在跑的服务
/etc/init.d/ip2d3 stop 2>/dev/null
pkill -9 -f 'cam3d_pipe'
sleep 2

# 2) 确认板子上是三域位流
cat /sys/class/fpga_manager/fpga0/state          # 期望 operating
# 如果不是，按 docs/38 第 2 节加载 ours3d_s5.bin

# 3) 启动（默认：彩色画面 + 不取反 + gamma 1.0）
cd /root/ip2
python3 cam3d_pipe.py --port 8080 --gamma 0.08 --color 1

# 4) 浏览器打开
#    http://<板子IP>:8080/
```

### 建议试的三组

```bash
# A. 室内 / 拍靶图：不取反，gamma 0.08
python3 cam3d_pipe.py --port 8080 --gamma 0.08 --color 1

# B. 逆光天空 / 找暗目标：取反
python3 cam3d_pipe.py --port 8080 --gamma 0.08 --invert 1 --color 1

# C. 只看画面不动参数（排查用）
python3 cam3d_pipe.py --port 8080 --gamma 1.0 --color 1
```

也可以启动后在网页上直接拖滑条，会实时生效（`/set` 接口），不用重启。

## 4. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 页面出来了但没框 | 先确认 `/info` 里 `raw` 是不是 0；三域 SE=5 只认 2~4 px，大目标本来就检不到 |
| 框是橙色的 | NPU 判 `d<0.5`（非无人机）；想看纯检测结果就把 NPU 关掉：`--npu 0` |
| 一片灰 | 说明用了 `--color 0`；改 `--color 1` |
| 页面白屏 | 浏览器强刷（Ctrl+Shift+R）；或 `tail -50 /root/ip2/ip2d3.log` 看报错 |
| 帧率很低 | 三域单帧 PL 4.2 ms + NPU 1.6 ms/候选；如果候选很多，NPU 会拖慢，`--npu 0` 可关 |
