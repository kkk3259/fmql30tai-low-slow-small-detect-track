## 0. 两条必须遵守的规则

| 规则 | 说明 |
|---|---|
| ① Python 命令一律写 **`py -3.12`** 或 **`<venv>\Scripts\python.exe`** | `python` 指向微软商店占位程序，运行时直接报 9009（这就是最初检测失败的原因） |

## 1. 第一档：今天装（软件基线必需）

```powershell
# 1.1 Git for Windows —— 版本管理与三分支协作
winget install --id Git.Git -e --accept-package-agreements --accept-source-agreements

# 1.2 Python 库（用已有的 3.12，不要重装 Python）
py -3.12 -m pip install --upgrade pip
py -3.12 -m pip install numpy opencv-python matplotlib pandas

# 1.3 VS Code —— 写脚本、看 Verilog、写 Markdown
winget install --id Microsoft.VisualStudioCode -e --accept-package-agreements --accept-source-agreements
```

**验证**（开一个新的 PowerShell 窗口再执行，让 PATH 生效）：

```powershell
git --version
code --version
py -3.12 -c "import cv2, numpy, matplotlib, pandas; print('cv2', cv2.__version__, '| numpy', numpy.__version__)"
```

期望：三条都打印出版本号，第 3 条无 ImportError。

## 4. 三个坑（不解决后面每步都会踩）

1. `python` 命令是 Store 占位程序 → 一切用 `py -3.12` 或 `<venv>\Scripts\python.exe`。若想让 `python` 也能用：设置 → 应用 → 高级应用设置 → 应用执行别名 → 关掉 `python.exe` / `python3.exe`。
2. 三个 Python 共存：3.12（`...\Programs\Python\Python312`）、Anaconda 3.9（`D:\ProgramData\Anaconda3`）、Anaconda 3.8（`D:\anaconda3`）。混用会把包装到意料之外的位置 —— 装包前先看一眼命令里写的是哪个解释器。
3. **装完要开新终端**：PATH 变更只对新开的窗口生效，否则会误以为"装失败"。
