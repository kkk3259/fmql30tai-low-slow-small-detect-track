# pl/constr/45t900 —— FMQL45T900 平台的引脚约束（待补）

## 为什么单独一轨

- **现在开发用**：FMQL45T900 核心板（型号丝印 `TES745D_V10` / "复旦微 FMQL45T900 核心模块"）
- **最终参赛用**：FMQL30TAI（悟净）

两者**封装不同**（45T900 = FCFBGA900，30TAI = FCBGA676），**引脚定义完全不通用** ——
所以约束文件必须分轨维护，**不能共用**。

## 两个平台的硬件差异（来自复旦微官网参数页）

| 项 | FMQL45T900 | FMQL30TAI |
|---|---|---|
| 逻辑资源 | 350K | 125K |
| LUT | 218,600 | 78,600 |
| BRAM | 19.2 Mb | 9.3 Mb |
| DSP | 900 | 400 |
| PS 主频 | 800 MHz | 1 GHz |
| 二级缓存 | 256 KB | 1 MB |
| **NPU** | **无** | **ZG330，8 TOPS@INT8** |
| 封装 | FCFBGA900 | FCBGA676 |
| 开发工具 | Vivado（兼容 Zynq-7045）/ FMSH 工具链 | Procise + Icraft |
| 片上接口 | 2×AXI_GP Master、2×AXI_GP Slave、**4×AXI_HP Slave** | 同类 |

## ⚠️ 资源预算纪律（最重要）

**在 45T900 上开发时，资源预算一律按 30TAI 卡死：**

```
LC   ≤ 125K
DSP  ≤ 400
BRAM ≤ 9.3 Mb
```

因为 45T900 的资源是 30TAI 的 **2.8 倍**，**不卡就会"在 45T900 上能跑、搬到 30TAI 放不下"**。

每次综合后请用 `tools/check_budget.py` 换算成"占 30TAI 的百分比"。
