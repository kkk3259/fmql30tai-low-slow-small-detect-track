## 快速开始（30 分钟跑通）

```powershell
# 1) 取代码
git clone https://github.com/kkk3259/fmql30tai-low-slow-small-detect-track.git
cd fmql30tai-low-slow-small-detect-track

# 2) 跑软件基线（会自动生成合成测试视频）
D:\lowslow\venv\Scripts\python.exe baseline\run.py --src synth          # v0 增强
D:\lowslow\venv\Scripts\python.exe baseline\detect_v1.py --src synth     # v1 检测
D:\lowslow\venv\Scripts\python.exe baseline\track_v2.py --src synth      # v2 跟踪

# 3) 跑完整集成流水线
D:\lowslow\venv\Scripts\python.exe ps\ps_app.py --src synth
```

**成功的标志**：`run.py` 打出 `+21.66 dB`；`track_v2.py` 打出 `跟踪成功率 98.7 %`；`ps_app.py` 打出各环节耗时并生成 `results/app_demo.mp4`。

> ⚠️ 必须用 `D:\lowslow\venv\Scripts\python.exe`，**不要用 `python`**（它指向微软商店的占位程序，会报错）。

## 硬约束提醒（摘自官方文件，写代码前先看）

- lite 版**未焊接**：PL 端千兆网、PL eMMC、CAN、RTC、SMA、SFP1、SDI 输入 3/4、SDI 输出、EEPROM、可调 GT 时钟、电流监控 → 视频输入只能走 **PS 侧**（USB 摄像头 / TF 卡序列 / 网口推流）
- **无 RTC**：断电后系统时间丢失，演示前必须对时
- HDMI **固定 720P60**（1080P60 部分显示器闪屏）
- USB2.0 带宽有限：720P YUYV 需 55 MB/s **超限** → 相机必须用 **MJPG**
- PS 主时钟必须 50MHz（不可用 33.333MHz）
