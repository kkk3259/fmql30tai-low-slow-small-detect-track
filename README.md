## 一、解决什么问题

低空慢速小目标（无人机、飞鸟、远处车辆）在画面里通常只有几像素到几十像素，且对比度低。
这类目标用「整图跑 CNN」的方案有两个结构性困难：一是像素太少，卷积网络在多级下采样后几乎拿不到特征；
二是整图推理的算力开销与目标数量无关，边缘设备上跑不动。

本作品把链路拆成三段异构分工：**PL 做像素级粗筛（快、便宜）、NPU 只判少量候选（准、贵）、PS 管流程与航迹（灵活）**，
使神经网络算力只作用在个位数候选上，而像素级运算全部卸载到硬件。

## 三、系统架构

```
USB 摄像头 (V4L2 640×360 灰度)
 │
 ▼
┌──────────────────────────────────────────────┐
│ PL · 像素级流水（Verilog 自研） │
│ 灰度化 → 形态学增强(Top-Hat/Black-Hat 可切) │
│ → CA-CFAR 自适应阈值 → 连通域标记 │
│ → 候选表（64 个，[x,y,area,peak]） │
└──────────────────┬───────────────────────────┘
 │ 512 位 PL-DDR / AXI-Lite 寄存器窗口
 ▼
┌──────────────────────────────────────────────┐
│ NPU · ZG330，只对候选 ROI 做二分类 │
│ crop 128×128 → cls128 前向 → 无人机概率 │
└──────────────────┬───────────────────────────┘
 ▼
┌──────────────────────────────────────────────┐
│ PS · 流程调度与航迹管理（Python） │
│ 卡尔曼预测 + 贪心匹配 + 航迹确认/删除 │
│ → 网页 MJPEG 推流（检测框/航迹/ID/概率叠加） │
└──────────────────────────────────────────────┘
```

三域并非并行独立运行，而是在**同一次上电、同一份位流**内协同：配置为 `PS7 + AI_Mate NPU + 自研检测器`，
加载后 `fpga_manager` 状态为 `operating`，检测器作为平台的一个自定义算子接入，与 NPU 共享 DDR 与中断资源。

## 五、快速开始

### 板端运行（需已加载位流）

```bash
# 三域链路（含 NPU 判别）
/etc/init.d/ip2d3 start
tail -f /root/ip2/ip2d3.log

# 浏览器打开
http://<板卡IP>:8080/
```

### 更换位流（**务必按此顺序，否则会挂死 PS 总线**）

```bash
pkill -9 -f 'cam_pipe[.]py'; pkill -9 -f 'cam3d_pipe[.]py' # 先停所有访问 PL 的进程
sleep 3
echo ours3d_s5.bin > /sys/class/fpga_manager/fpga0/firmware
sleep 3
cat /sys/class/fpga_manager/fpga0/state # 必须是 operating
```

> 原因：重配 PL 时若还有进程持有 `/dev/mem` 映射或未完成的 AXI 事务，会挂死 PS 总线，
> 只能断电重启。失联后若 SSH 不通，只能人工断电（SW8 拨 ON 重新上电）。

### 离线评测

```bash
python3 ps/eval_testset.py # 检测召回/虚警评测
python3 ps/full_pipeline.py --src demo.mp4 --out out.mp4
```

## 六、技术路线上的两个关键判断

**其一，形态学方向从亮斑改为暗斑。** 低小慢目标在明亮天空背景下多呈暗剪影，
单路 Top-Hat（提取亮斑）的假设被实测推翻：同为 topk=64 时，Black-Hat 单路召回 87.0%，
双路各取 64 再截断仅 85.0%，而候选数低 3.7 倍——暗斑通道的干扰源天然少一个量级。

**其二，三域同板不走官方网表，改走自定义算子。** 我们逐端口判读了 `AI_Mate.edif` 的 135 个顶层端口，
发现 M_AXI_GP0/GP1 与 S0~S3_AXI_HP 只有握手类信号，没有地址与数据线——官方 AI_Mate 的数据走的是私有总线。
因此改为按平台的算子扩展机制接入（`ip2_user_op.v`），检测器成为 AI 协处理器的一个自定义算子，
代价是自行承担 512 位 → 检测器像素流的适配，收益是不必触碰 AI_Mate 的任何引脚。
