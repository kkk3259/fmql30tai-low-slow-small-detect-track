# baseline/ —— 纯软件基线

本目录是**全部在 ARM 核心上用 Python/OpenCV 实现**的算法基线，用于与 PL 硬件加速版对比。
报告里「PL 比软件快 5.5 倍」这类结论，参照物就是这个目录的代码。

| 文件 | 作用 |
|---|---|
| `detect_v1.py` | v1：CA-CFAR 检测（形态学增强 + 自适应阈值 + 连通域）|
| `detect_v3.py` | v3：加入时域增强（多帧累积 / 运动补偿 / 背景滑动平均）|
| `track_v2.py` | v2：卡尔曼预测 + 贪心匹配 + 航迹管理 |
| `run.py` | 端到端入口（7 环节 / 5 接口的完整框架）|
| `timing.csv` | 各环节耗时基准 |

## 关键对比数据

| 环节 | 纯软件（本目录）| PL 硬件（三域位流）| 加速比 |
|---|---|---|---|
| 检测单帧 | 57.87 ms | **4.19 ms** | **13.8×** |
| 形态学 + CFAR + CCL | 14.3 ms | 含在上面 | — |

> 注：软件版在 640×360 灰度图上跑，与 PL 同分辨率、同算法。逐像素误差 ≤1 灰阶。
